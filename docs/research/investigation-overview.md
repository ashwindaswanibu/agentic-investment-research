# Investigation overview verification

2026-10-05. Bounded UI change: make a saved investigation readable before asking
the user to navigate individual artifacts. No research result was generated by
this change and no new backend or framework was added.

The overview presents the saved run summary or recorded claim, research question,
hypothesis disposition, competing explanation, falsification condition, findings,
missing evidence, source records, analysis/review and actual task execution.
Latest dossier selection uses timestamps rather than response ordering. It shows
at most three claims, with access to the full dossier. Source checks remain
distinct from interpretation quality. Rejected hypotheses stay visibly rejected.

Source links open the exact persisted artifact; references outside the current
case use the existing artifact API. Unavailable references and references to
non-evidence records produce an error. No arbitrary reference content is rendered
as a source. Protected evaluation artifacts do not supply overview findings.
The source shelf distinguishes local records from references stored elsewhere.
